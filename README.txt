Anime Box GitHub Pages fix

Upload index.html, 404.html, style.css, and script.js to the ROOT of the branch/folder configured in GitHub Pages. Keep all four files together. GitHub Pages uses 404.html as a fallback for client-side routes such as /home/detail/naruto-shippuden. Root-relative /style.css and /script.js paths are set for your username.github.io root site.

After upload, open Settings > Pages and confirm the correct branch and root folder are selected. Wait for the Pages deployment to finish, then test the site and direct detail URL.
