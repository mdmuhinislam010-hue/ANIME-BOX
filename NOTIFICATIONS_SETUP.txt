AnimeBox In-Site Notifications (Phase 1)
========================================

This ZIP adds the foreground notification center to the existing User Website.
It uses the same Firebase Realtime Database project already configured in the site:
  ttttt-9bee0

Firebase path:
  notifications/{notificationId}

Admin HTML changes:
- Adds a User Notifications manager for manual announcements.
- Automatically publishes a notification after a NEW Movie, Anime, Series/TV card is added through the standard content form and the built-in AniList/TMDB auto-add flows.
- Editing an existing card does not send a duplicate notification.

User Website changes:
- Adds a bell icon with unread count in the top navigation.
- Shows notification image, title, message, type, and time.
- Clicking an item opens its linked detail page.
- Shows a small in-site toast while the website is open when a new notification arrives.
- Read state is stored in this browser's localStorage.

Important:
- This is in-site / foreground notification only. It does NOT yet send browser push while the website is closed.
- Background push via Render + Firebase Cloud Messaging will be a separate later phase.
- No Firebase Auth project, OTP function, or login code was changed.
- The website must be served over HTTPS for normal browser functionality.
- Existing Realtime Database rules must allow the Admin to write notifications and the User Website to read them. Review rules before deployment; do not make the entire database publicly writable.
